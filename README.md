# 🏐 Evolley

Sistema de gestão esportiva para equipes de voleibol.

O Evolley foi desenvolvido para auxiliar treinadores, comissões técnicas e equipes no gerenciamento de atletas, partidas, treinos e análises de desempenho através de scout esportivo.

---

# Objetivo

Criar uma plataforma moderna capaz de centralizar:

- Cadastro de equipes
- Cadastro de atletas
- Gestão de partidas
- Scout em tempo real
- Avaliações de treino
- Estatísticas
- Evolução dos atletas
